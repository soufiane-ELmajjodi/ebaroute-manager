# Server Manager Backend

This is the Node.js/Express backend for the GPS Management System.

## Setup

1. Open a terminal in this directory (`server-manager`).
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the server at `http://localhost:3001`.

## Features
- Persistence via `db.json`.
- CORS enabled for the frontend.
- Extensible for MySQL or other databases.
